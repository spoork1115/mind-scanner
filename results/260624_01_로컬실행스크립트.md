# 로컬 실행 스크립트 생성 보고서

Next.js 웹 애플리케이션의 로컬 실행을 자동화하고, 한글 인코딩 이슈를 원천 차단하기 위해 순수 영문으로 구성된 Windows 배치 파일(`run.bat`)을 생성하였습니다.

## 1. 생성된 파일 정보
- **파일명:** `run.bat`
- **위치:** 프로젝트 루트 디렉토리 (`d:\40. PYTHON\mind-scanner\run.bat`)

## 2. 배치 파일 코드 내용
```bat
@echo off
title Mind Scanner Local Server
echo ==========================================
echo Starting Mind Scanner Local Server...
echo ==========================================

:: Check if Node.js is installed
where node >nul 2>nul
if %errorlevel% neq 0 (
    echo Error: Node.js is not installed or not in PATH.
    echo Please install Node.js first.
    pause
    exit /b 1
)

:: Check if node_modules exists, if not, run npm install
if not exist "node_modules\" (
    echo node_modules not found. Installing dependencies...
    call npm install
    if %errorlevel% neq 0 (
        echo Error: npm install failed.
        pause
        exit /b 1
    )
)

:: Start the development server and open browser
echo Starting Next.js development server...
start http://localhost:3000
call npm run dev

pause
```

## 3. 주요 기능 명세
1. **Node.js 설치 확인 (`where node`):** 시스템에 Node.js가 설치되어 있으며 환경 변수(PATH)에 등록되었는지 검증합니다.
2. **의존성 자동 설치 (`npm install`):** `node_modules` 디렉토리의 유무를 감지하여, 없는 경우 자동으로 필요한 라이브러리를 내려받습니다.
3. **브라우저 자동 호출 (`start http://localhost:3000`):** 서버 실행과 동시에 브라우저를 열어 사용자 편의성을 높입니다.
4. **개발 서버 기동 (`npm run dev`):** Next.js 개발 서버를 실행하여 로컬 개발 환경을 로드합니다.
5. **예외 처리 및 일시 정지 (`pause`):** 실행 중 문제가 발생하거나 프로세스가 종료되었을 때, 명령 프롬프트 창이 바로 닫히지 않고 오류 원인을 확인할 수 있도록 대기시킵니다.
