## 1. 3차 버그 원인 및 조치 계획

### 1.1. 온보딩 첫 화면의 거대 중간 공백 현상
- **원인**: `src/app/page.js` 파일 내의 바깥 컨테이너(`.onboarding-container`)에 `min-height: 100vh`가 적용된 상황에서, 최하단 모드 선택 카드 영역(`.mode-selection-zone`)에 **`margin-top: auto`** 스타일이 적용되어 있었습니다. 이로 인해 소형 화면이나 일반 모바일 해상도에서 두 컴포넌트 사이가 강제로 찢어지며 부자연스러운 거대 여백이 형성된 것으로 확인되었습니다.
- **해결안**: `.mode-selection-zone` 의 `margin-top: auto` 설정을 제거하고, 자연스러운 간격인 `margin-top: 24px`로 통일하여 한 화면에 깔끔하게 집약되도록 수정합니다.

### 1.2. 타로 2단계 및 각 화면 하단 버튼('.thumb-zone-action') 겹침 오류
- **원인**: 모바일 뷰포트 내부에서 콘텐츠 높이가 화면 크기를 넘어설 때 스크롤이 일어나야 하지만, 하단 버튼 바(`.thumb-zone-action`)가 `absolute` 형태로 화면 하단에 고정되어 콘텐츠를 덮어버리고 있었습니다. 컨테이너 자체에 하단 패딩을 주었으나, 그리드와 카드 리스트가 늘어나는 경우 여전히 겹침을 완벽하게 방지하지 못했습니다.
- **해결안**: 각 입력 양식이나 그리드 영역(`.spread-selection-grid`, `.templates-list`, `.profile-form`)의 하단 마진(`margin-bottom: 110px`)을 명시적으로 크게 확보하여, 어떠한 기기 해상도에서도 스크롤을 내렸을 때 콘텐츠가 고정 버튼 위로 안전하게 밀려 올라와 겹침이 원천적으로 차단되도록 해결하겠습니다.

### 1.3. 결과 화면 타로 카드 이미지 크기 극대화
- **원인**: 타로 결과 페이지에서 일러스트의 해독 가독성을 주기 위해 이미지 크기를 일부 상향하였으나, 여전히 디테일을 읽기엔 시각적으로 작게 느껴진다는 피드백이 있었습니다.
- **해결안**: 
  - 단일 카드 뷰의 카드 박스(`.tarot-card-image-box.single-card`) 크기를 너비 `260px`, 높이 `416px`로 한층 더 거대하게 확대합니다.
  - 3장 카드 뷰의 개별 아이템 패딩을 최소화하고 이미지 비율과 섀도우를 리터칭하여 한 화면 내에서 미려하게 돋보이도록 최적화하겠습니다.
