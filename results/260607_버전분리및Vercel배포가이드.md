## 1. 두 버전의 차이점

| 구분 | 설문 전용 버전 | 타로+설문 통합 버전 |
| :--- | :--- | :--- |
| **Git 브랜치** | `main` ⭐ 기본 | `tarot-mode` |
| **메인 화면** | 단일 시작 버튼 | 타로/설문 2가지 선택 |
| **결과 화면** | 설문 분석 결과만 | 타로 카드 + 설문 분석 결과 |
| **Vercel 용도** | Production (기본 도메인) | Preview (별도 URL) |

> [!note] **브랜치란?**
> 같은 코드 저장소(GitHub) 안에서 서로 다른 버전을 독립적으로 관리하는 공간입니다.
> 서랍장에 비유하면, 같은 서랍장(GitHub 레포)에 `main`이라는 서랍과 `tarot-mode`라는 서랍이 각각 들어있는 것과 같습니다.

## 2. Vercel에서 각 버전 실행하는 방법

### 2.1. 설문 전용 버전 (기본 Production 배포)

이미 GitHub의 `main` 브랜치가 Vercel Production으로 연결되어 있다면, **별도 설정 없이** 자동으로 최신 `main` 브랜치 코드가 배포됩니다.

**확인 방법:**
1. [Vercel 대시보드](https://vercel.com/dashboard) 접속
2. 해당 프로젝트 클릭
3. `Settings` → `Git` 탭에서 **Production Branch**가 `main`으로 설정되어 있는지 확인

```
✅ Production Branch: main  →  설문 전용 버전 자동 배포
```

### 2.2. 타로+설문 통합 버전 (별도 Preview URL)

Vercel은 GitHub의 **모든 브랜치를 자동으로 Preview 배포**해 줍니다.
`tarot-mode` 브랜치를 GitHub에 Push하면 Vercel이 자동으로 별도 URL을 생성합니다.

**Preview URL 확인 방법:**
1. [Vercel 대시보드](https://vercel.com/dashboard) 접속
2. 해당 프로젝트 클릭
3. `Deployments` 탭에서 `tarot-mode` 브랜치 항목 확인
4. 해당 배포의 URL 복사

**자동 생성되는 URL 형식:**
```
https://mind-scanner-git-tarot-mode-spoork1115.vercel.app
```

> [!tip] **고정 도메인 부여하기 (선택사항)**
> Vercel 대시보드 → `Settings` → `Domains` 에서 `tarot-mode` 브랜치에 별도 커스텀 도메인(예: `tarot.mindmirror.com`)을 연결할 수 있습니다.

## 3. 코드 변경 후 배포 방법 (반복 작업 가이드)

각 버전에서 수정 작업 후 배포하는 방법입니다.

### 설문 전용 버전 수정 → 배포

```
1. main 브랜치에서 코드 수정
2. git add .
3. git commit -m "수정 내용 메모"
4. git push origin main
→ Vercel이 자동으로 Production 배포 시작!
```

### 타로+설문 통합 버전 수정 → 배포

```
1. git checkout tarot-mode  ← 타로 버전 브랜치로 이동
2. 코드 수정
3. git add .
4. git commit -m "수정 내용 메모"
5. git push origin tarot-mode
→ Vercel이 자동으로 Preview 배포 시작!
```

> [!warning] **주의사항**
> 각 버전의 수정은 반드시 해당 브랜치에서 작업해야 합니다.
> `main` 브랜치에서 타로 버전 코드를 수정하면 두 버전이 섞이는 혼선이 생깁니다.
